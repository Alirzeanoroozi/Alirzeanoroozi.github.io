# Alireza Noroozi

Personal site at [Alirzeanoroozi.github.io](https://Alirzeanoroozi.github.io).

Static HTML and CSS, hosted on GitHub Pages.

Edit `index.html`, `cv.html`, and `css/styles.css`. The profile photo is `img/profile.jpg` and the CV is `pdf/Alireza_Noroozi_CV.pdf`.

## Blogs

1. Add a Markdown file in `posts/`, for example `posts/my-post.md`:

```md
---
title: My post title
date: 2026-09-09
summary: One-line preview on the Blogs page.
---

Your Markdown goes here.
```

2. Put the filename (without `.md`) at the top of `posts/index.json`:

```json
["my-post", "hello-world"]
```

The post will show up under the Blogs tab at `blogs.html`.
